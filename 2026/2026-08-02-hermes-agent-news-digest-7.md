# Hermes Agent Quotidien #7

Paper Agent : Hermes Agent depuis une liseuse ebook, et tip compilation locale du Desktop.

## Paper Agent : Hermes Agent contrôlé par liseuse ebook

Marco Franzon (@mfranz_on) a publié le 1er août ce qu'il appelle Paper Agent : Hermes Agent piloté depuis un ebook reader à encre électronique.

Le principe est simple : pendant que vous lisez sur votre liseuse, les agents continuent de tourner en arrière-plan. Quand ils ont besoin d'une intervention humaine (push, deploy, rm -rf...), une carte apparaît sur l'écran e-ink. Pas de téléphone, pas de laptop.

"Ce n'est pas une notification de plus, ça ressemble plus à signer des petites missions", commente un observateur dans les réponses.

Teknium a relayé le post en disant "love seeing the community run Hermes Agent on all kinds of different hardware" et "very cool and unusual setups". Le projet fonctionne aussi avec Claude Code.

## Hermes Desktop se compile localement sur toute plateforme

Teknium a partagé le 1er août un tip méconnu : Hermes Desktop fonctionne sur Intel Mac et toute surface sans installateur officiel.

La commande est simple : installer le CLI, puis lancer `hermes desktop` qui compile l'application localement. Cela évite d'attendre un binaire pré-construit pour les architectures moins communes.

"Same applies on any other surface we dont have an official installer for", précise Teknium. Le tip concerne en priorité les Mac Intel (la version officielle suppose Apple Silicon), mais s'applique à tout système sans build distribué.

> Source : [@Teknium, 1er août 2026](https://x.com/Teknium/status/2083556018072817681)
