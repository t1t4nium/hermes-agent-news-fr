# Hermes Agent Quotidien #8

Optimisations massives (Nemo Relay), Qwen 3.8 Max intègre Hermes Agent, DeepSeek V4 Flash -90%, et tutoriel Buzz.

## Optimisations Hermes Agent : -90 % de tokens, nouveau modèle imminent

Teknium a annoncé le 2 août qu'Hermes Agent vient de recevoir des optimisations profondes, identifiées grâce à l'outil Nemo Relay de NVIDIA et plusieurs autres stratégies.

Les gains sont chiffrés :

- **36 % de tours en moins** par tâche (de 6,9 à 4,4)
- **46 % d'erreurs outil en moins** par tâche (de 3,3 à 1,8)
- **87 % de tokens gâchés** par tâche complète (de 1,2M à 159K)
- **91 % de tokens d'entrée** par tâche (de 5,7K à 488)

Ces résultats viennent de l'analyse de 250 000 conversations de Teknium avec son Hermes, en traçant les tours inutiles, les erreurs et la consommation schéma pour identifier où chaque octet pouvait être économisé.

Les optimisations sont déjà disponibles dans Hermes Agent via `hermes update`. Teknium précise qu'une mise à jour version complète (v0.19.2 ou v0.20.0) sera publiée le lendemain (3 août).

> Source : [@Teknium, 2 août 2026](https://x.com/Teknium/status/2084065915004747888) - [@Teknium, 2 août 2026](https://x.com/Teknium/status/2084066111625318789)

## DeepSeek V4 Flash 0731 -90 % sur le Nous Portal

Nous Research a annoncé le 2 août une réduction de 90 % sur DeepSeek V4 Flash 0731 via le Nous Portal, en partenariat avec Novita Labs, pour les 7 prochains jours.

Aux prix réduits, le modèle est plus de 1 000 fois moins cher que Fable 5 sur des tâches comparables, tout en le battant sur Terminal-Bench 2.1.

Teknium commente : "L'intelligence est si bon marché que vous voulez la mesurer pour montrer que quelques centimes suffisent à bâtir un empire."

> Source : [@NousResearch relayé par @Teknium, 2 août 2026](https://x.com/NousResearch/status/2083953441571742191) - [@Teknium, 2 août 2026](https://x.com/Teknium/status/2083956677947383927)

## Qwen 3.8 Max intègre Hermes Agent dans sa vidéo de lancement

Le 3 août, Qwen (Alibaba) a annoncé Qwen 3.8 Max, un nouveau modèle de codage, ainsi qu'un modèle local 27B. Dans leur vidéo de lancement, Hermes Agent a été mis en avant par Alibaba_Qwen.

"Merci @Alibaba_Qwen d'avoir mis en avant Hermes Agent dans la vidéo de lancement !", a répondu Teknium.

C'est une reconnaissance notable pour le projet : Qwen, l'un des principaux acteurs du domaine, a choisi d'utiliser Hermes Agent comme plateforme de démonstration pour son nouveau modèle.

> Source : [@Teknium, 3 août 2026](https://x.com/Teknium/status/2084140512777560537) - [@Alibaba_Qwen, 3 août 2026](https://x.com/Alibaba_Qwen/status/2084093402967396594)
